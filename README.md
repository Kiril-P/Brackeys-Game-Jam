# Brackeys Game Jam — Strange Places

A Godot prototype exploring gravity, portals, and strange spaces, with a companion guiding the player through a hub and levels.

## In this repository

- Gravity-aware player movement and portal transitions.
- A hub with level unlocking and saved progression.
- Companion tutorial/subtitle systems and visual shader experiments.

## Run locally

Open `project.godot` in Godot 4.5 or a compatible version, let imports finish, and press **F5**.

This is a prototype, not a verified finished release. [Project state notes](state.md) document implementation progress and known issues, including portal-lock visuals. [Gameplay design notes](GAMEPLAY_MECHANICS_PLAN.md) describe the intended mechanics; planned features should not be treated as shipped.
